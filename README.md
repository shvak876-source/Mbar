# MBAR – אתר החנות

אתר תדמית סטטי לחנות MBAR – חנות הלבשה לגברים, תל חי 100, קריית שמונה.

## מבנה
- `index.html` – כל תוכן האתר (עברית, RTL)
- `styles.css` – עיצוב
- `script.js` – תפריט מובייל ואנימציות גלילה
- `images/` – תמונות

## החלפת תמונות
התמונות שבתיקיית `images/` נחתכו מצילום מסך של גוגל ולכן באיכות נמוכה.
מומלץ להחליף אותן בתמונות המקוריות באותם שמות קבצים:
- `store.jpg` – חזית החנות (משמשת גם כרקע הראשי)
- `look-suits.jpg` – לוק סטים / חליפות
- `look-cargo.jpg` – לוק מכנסיים

## צפייה מקומית
פשוט לפתוח את `index.html` בדפדפן, או:
```
python3 -m http.server 8000
```
