# MBAR – אתר החנות

אתר תדמית סטטי לחנות MBAR – חנות הלבשה לגברים, תל חי 100, קריית שמונה.

## מבנה
- `index.html` – כל תוכן האתר (עברית, RTL)
- `styles.css` – עיצוב
- `script.js` – תפריט מובייל ואנימציות גלילה
- `images/` – תמונות

## מערכת עיצוב
העיצוב נבנה לפי הסקיל UI UX Pro Max (פרופיל "E-commerce Luxury" + Exaggerated Minimalism):
- צבעים: שחור-אבן (`#0c0a09`, `#1c1917`), רקע `#fafaf9`, הדגשה זהב אחת (`#c9a96a` על כהה, `#8a5a0a` על בהיר).
- פונטים: Frank Ruhl Libre לכותרות, Heebo לטקסט.
- נגישות: ניגודיות 4.5:1, פוקוס נראה, קישור "דלגו לתוכן", אייקוני SVG, יעדי מגע 44px, חלון מוצר נגיש מהמקלדת.

כל הצבעים מוגדרים כמשתנים בראש `styles.css`.

## תמונות
- `photos/` – התמונות המקוריות מהאינסטגרם, בלי שינוי.
- `images/catalog/` – תמונות הקטלוג: 900×1200, חתוכות מהסנטר ולמטה (בלי פרצופים). השם = מספר התמונה המקורית.
- `images/store.jpg` – חזית החנות (רקע ראשי), `images/look-evening.jpg` – לוק ערב ללוקבוק.

כדי להוסיף פריט לקטלוג: מוסיפים תמונה ל-`images/catalog/` ושורה ל-`products.js`.

## עדכון האתר
אחרי שינוי ב-`styles.css`, `script.js` או `products.js` מעלים את המספר ב-`?v=` בקישורים שלהם ב-`index.html` (למשל `?v=4` ← `?v=5`), כדי שדפדפנים לא יציגו גרסה ישנה מהמטמון.

## צפייה מקומית
פשוט לפתוח את `index.html` בדפדפן, או:
```
python3 -m http.server 8000
```
